أقسام الدليل والنظام الميداني

جدول الأفراد (Roster)

استعراض سلسلة القيادة، الضباط، وتعديل الصلاحيات الميدانية مباشرة عبر النظام.

الدخول للجدول

دليل الرتب (Ranks)

عرض الشارات، الرتب، المهام الموكلة، والتسلسل القيادي للشرطة.

عرض الرتب

أكواد الاتصالات (10-Codes)

أكواد الراديو، حالات الطوارئ (Code 0, Code 3)، والإشارات الرسمية للعمليات.

استعراض الأكواد

دليل الملابس (Uniforms)

التجهيزات الرسمية، أزياء الدوريات، SWAT، والأقسام المتخصصة.

عرض الزي الرسمي

القوانين واللوائح (Laws)

اللوائح الإدارية، القوانين الجنائية، العقوبات، والمخالفات المرورية والميدانية.

قراءة القوانين

الإجراءات الميدانية

بروتوكولات الاعتقال، التفتيش، المطاردات، المفاوضات، وقواعد استخدام القوة.

استعراض الإجراءات

سجل المطلوبين (Wanted)

قائمة المشتبه بهم، درجات الخطورة، والتحديثات المباشرة عبر Firestore.

قائمة المطلوبين

نظام التقارير (Reports)

تقديم تقارير الحوادث، المداهمات، وتوثيق المحاضر الرسمية بملفات وصور.

تقديم تقرير
